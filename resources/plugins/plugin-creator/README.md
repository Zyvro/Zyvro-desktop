# Plugin Creator

Describe a plugin idea; the agent designs it, writes it into
`.zyvro/plugins/<name>/` in the open project, and checks that Zyvro Studio
loads it. Try it from the chat's side bar, then publish it from
Store › Publish › Agent plugins.

The five skills in `skills/` are the whole method: design, format, skill
writing, testing and publishing. They are also a good read if you write a
plugin by hand.
